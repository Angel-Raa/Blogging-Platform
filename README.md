# Blogging Platform 🚀

Una plataforma de blogs moderna construida con Spring Boot y Vuejs.

## Características principales ✨

- Creación y gestión de posts de blog
- Autenticación de usuarios
- Interfaz responsive y amigable
- API RESTful 
- Sistema de comentarios

## Stack tecnológico 💻

### Backend (Spring Boot)
- **Lenguaje**: Java 11+
- **Framework**: Spring Boot 3.4.5+
- **Base de datos**: PostgreSQL
- **Seguridad**: Spring Security
- **API Docs**: Swagger

### Frontend (Vuejs)
- **Lenguaje**: TypeScript
- **Framework**: Vuejs
- **Estado**: Pinia
- **Estilos**: Tailwind
- **Routing**: Vuejs Router

## Requisitos previos 📋

- JDK 11+
- Node.js 16+
- Maven/Gradle (según configuración)

## Instalación ⚙️

### Backend
```bash
cd backend
mvn spring-boot:run
# o
./gradlew bootRun
```
